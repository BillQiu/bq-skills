# 日报模板

```md
# 每日论文清单 - {YYYY-MM-DD}

## 今日概览

- 日期：{绝对日期}
- 数据源：{arXiv + Hugging Face Papers}
- 候选池：{原始候选数}
- 过滤后：{保留数}
- 今日结论：{一句话总结今天的主题分布与质量}

## Top 5 推荐

- 链接：{URL}
- 来源：{arXiv / HF / 多来源}

- 命中方向：{agent / codegen / bug-fix / planning / synthetic-data / RAG ...}
- 推荐理由：{2-4 句，说明问题、相关性、工程潜力}
- 风险提示：{1 句}
- 建议动作：{建议交给 bq-paper 深读 / 先略读摘要即可}

## 未入选类型摘要

- 今日主要剔除的论文类型：{纯理论 / 跨学科应用 / 应用包装 / 弱相关工作 ...}
```

## 约束

- 不要输出成原始链接堆砌
- 不要照搬摘要
- 不要把热度解释成质量
- 结论必须能支持“下一步读哪篇”这个决策
